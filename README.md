# Camilius

Describe your business — Camilius builds you a live website, complete with an AI agent that answers customer questions and books appointments, day or night.

## How it works

1. The owner describes their business in a few sentences (or a voice note, or an uploaded document)
2. AI generates a full page draft: tagline, "about" text, working hours, price list, FAQ
3. That same content becomes the knowledge base for a built-in AI chat agent on the site — it answers customer questions and can book appointments straight into the business's calendar
4. The owner can keep refining the page through a back-and-forth "draft this with AI" chat

## Features

- **AI website generation** from a short description, voice note, or document — tagline, about section, hours, services/prices, FAQ
- **Built-in AI chat agent** on every generated site, answering from that business's own knowledge base
- **Booking system** — configurable appointment slots, straight into the owner's schedule, with reminders
- **Custom domains** and multi-language pages
- **Subscriptions & billing** — Stripe and Paddle, Starter/Pro plans
- **Mobile app** (Android, via Capacitor) with push notifications

## Tech stack

- **Backend:** Python / Flask
- **AI:** OpenAI (page generation, chat agent, voice transcription)
- **Database:** PostgreSQL
- **Billing:** Stripe, Paddle
- **Mobile:** Capacitor (Android)
- **Deployment:** Docker, Railway

## Status

Actively developed solo project. Core flow — describe a business, get a generated site with a working AI agent and booking — is implemented end-to-end.
